Safe genesis registry

Each Safe's creation parameters, written once and kept on chain, so the same Safe can be deployed at the same address on any other chain. This page reads the registry contract directly from your browser; nothing comes from a server. A name is a label: whoever writes the record first chooses it, and the Safe itself can rename it at any time, so only a name marked “named by the Safe” comes from its owners. Names may repeat; the address is the Safe's identity.
